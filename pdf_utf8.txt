ABSTRACT
LecScheduler is an intelligent academic scheduling and timetable automation platform designed to simplify
lecture management in educational institutions. Traditional scheduling methods are highly manual, time-
consuming, and error-prone. Problems such as lecture clashes, classroom conflicts, delayed
announcements, and inefficient timetable updates create operational difficulties for institutions.
The proposed system introduces a modern cloud-based and AI-powered solution that automates lecture
scheduling, substitution handling, timetable updates, and conflict detection in real time. The application is
developed using modern web technologies including HTML5, CSS3, JavaScript, Firebase Firestore, Firebase
Authentication, and Firebase Cloud Functions.
The system uses an event-driven serverless architecture and supports real-time synchronization between
students, faculty, and administrators. It also integrates Artificial Intelligence using the Google Gemini API to
intelligently parse timetable PDFs and convert unstructured timetable data into machine-readable JSON.
The system improves scheduling accuracy, minimizes administrative workload, ensures secure access
control, and provides students with instant timetable updates. The application also supports offline access
using service workers, making it highly reliable even in unstable internet conditions.
Keywords: Cloud Computing, Firebase, Artificial Intelligence, Scheduling System, Timetable Automation,
Real-Time Database, Serverless Computing.

CHAPTER 1 – INTRODUCTION
1.1 Introduction
Educational institutions handle large numbers of lectures, classrooms, faculty schedules, and student
timetables every day. Managing these operations manually often results in scheduling conflicts, inefficient
communication, and excessive administrative effort.
LecScheduler is designed as a smart automated academic scheduling platform that digitizes and simplifies
timetable management. The system enables educational institutions to manage lectures efficiently using
cloud technologies and real-time synchronization.
The application automates timetable generation, faculty substitutions, conflict detection, and schedule
updates while ensuring that all users receive instant information through a centralized digital platform.
1.2 Motivation
The motivation behind this project comes from the limitations of traditional academic scheduling systems.
Most institutions still rely on manual processes, spreadsheets, or static notices for managing schedules.
Common issues include:
Double booking of classrooms
Faculty scheduling conflicts
Delayed timetable updates
Communication gaps
Difficulty in handling substitutions
High administrative workload
The project aims to solve these challenges by using cloud-native technologies and intelligent automation.

CHAPTER 6 – SYSTEM ARCHITECTURE
6.1 Architectural Paradigm
The system follows a modern cloud-native architecture.
Serverless Computing
Backend logic is executed using Firebase Cloud Functions without managing physical servers.
Event-Driven Architecture
The application reacts to events such as database changes and file uploads.
Single Page Application (SPA)
The frontend dynamically updates content without reloading the entire webpage.
6.2 Architecture Flow
User logs into the system.
Authentication is verified using Firebase Authentication.
Timetable data is fetched from Firestore.
Real-time updates are synchronized instantly.
AI processes uploaded timetable PDFs.
Conflict detection validates scheduling operations.

CHAPTER 10 – ALGORITHMS USED
10.1 Conflict Detection Algorithm
The system prevents overlapping lectures using time interval validation.
Condition:
If (NewStartTime < ExistingEndTime AND NewEndTime > ExistingStartTime)
Then a conflict exists.
Advantages
Prevents double booking
Ensures schedule accuracy
Maintains resource integrity
10.2 Batched Write Algorithm
The system uses Firestore Batched Writes to perform atomic database operations.
Benefits:
Data consistency
Improved reliability
Prevents partial database corruption
